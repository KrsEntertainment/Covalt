# Covalt — локальный генератор 2D-видео

Covalt — небольшое рабочее приложение на Python + HTML. Оно принимает описание
сцены, прогоняет его через локальный генератор движения, рисует кадры и
собирает их в обычный MP4. Облачные API, Hugging Face и скачанные веса не
используются.

Это не обещание «киношной» text-to-video модели: Covalt рассчитан на красивые
простые 2D-сцены — шар, квадрат, треугольник, звезда, кольца, волны, город и
закат. Но видео действительно состоит из кадров, а не является анимированной
HTML-картинкой: его можно смотреть в браузере и скачать как `.mp4`.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Откройте <http://localhost:5000>. Для публикации войдите как администратор,
используя пароль `9086` (для реального сервера задайте переменную
`COVALT_ADMIN_PASSWORD`).

## GitHub Codespaces

Если под «GitHub Space» имеется в виду **GitHub Codespaces**, в репозитории уже
есть `.devcontainer/`:

1. Откройте репозиторий на GitHub → **Code → Codespaces → Create codespace**.
2. Дождитесь завершения `setup.sh`: он установит Python-зависимости и Ollama.
3. `start.sh` запустит Ollama, скачает `qwen2.5:1.5b` и Covalt.
4. Откройте автоматически forwarded порт **5000**. Это будет рабочий URL сайта.

Если Codespace уже создан, команды вручную:

```bash
bash .devcontainer/setup.sh
bash .devcontainer/start.sh
```

Модель, установленная на вашем Windows-компьютере, не переносится в Codespace:
это отдельная Linux-машина. В Codespace модель нужно скачать ещё раз. Порт
`11434` оставлен private, а наружу публикуется только Covalt на порту `5000`.

Также можно запустить:

```bash
# Тренировочное мультимодальное демо из исходного примера
.venv/bin/python train.py
.venv/bin/python demo.py
```

## Как пользоваться

1. Введите промпт на русском или английском. Например: `Неоновая звезда
   вращается в космосе`.
2. Выберите длительность от 1 до 300 секунд и нажмите **Сгенерировать видео**.
3. После окончания ролик появится у администратора в отдельном блоке
   **«Недавние генерации»** как `DRAFT`. Там можно открыть превью и проверить
   весь ролик.
4. Войдите с паролем `9086` и нажмите у выбранного ролика **Опубликовать** —
   после этого любой посетитель сможет смотреть ролик и скачивать MP4.
5. Неподходящий ролик можно удалить прямо из блока недавних генераций.

Генерация выполняется в фоне, поэтому страницу не нужно держать заблокированной.
Для пяти минут видео может понадобиться заметное время и место на диске.

## Новые режимы Covalt

- **Видео и картинки** — временно поставлены на паузу в интерфейсе, пока мы
  отдельно проверяем понимание текста. Сам код локального MLP-рендерера и
  прежний архив не удалены.
- **Чат** — Covalt помнит своё имя и создателя `RYNico corp.`, разбирает
  сцену, действие, палитру, настроение и камеру. Если задать
  `COVALT_LLM_URL`, можно подключить любой OpenAI-compatible LLM; без него
  работает честный локальный intent-движок.
- **Картинки** — PNG-кадр создаётся тем же обученным локальным renderer-ом.
- **Поиск в интернете** — включается переключателем в чате и использует
  DuckDuckGo HTML без API-ключа, показывая источники и ссылки. Если сеть
  недоступна, Covalt сообщает об этом и не выдумывает результаты.
- **Новости** — администратор может создавать, редактировать, публиковать и
  удалять новости внизу главной страницы.
- **Наши тесты** — отдельная страница `/tests` с повторяемыми проверками
  идентичности, смысла, разнообразия ответов, честного незнания и web-режима.

### Дополнительный чат-модуль

Для настоящего текстового диалога выбран локальный Ollama backend:

```bash
ollama serve
ollama pull deepseek-r1:7b
# Если тег другой, укажите его явно; без переменной Covalt сам ищет DeepSeek,
# затем Qwen среди установленных моделей.
export COVALT_OLLAMA_MODEL="deepseek-r1:7b"
.venv/bin/python app.py
```

Если Ollama не запущена или модель не скачана, Covalt **не называет fallback
нейросетью**: в интерфейсе будет `TEXT MODEL / NOT CONNECTED`, а в тестах
`Настоящая модель подключена` и `Первый диалог` получат `CHECK`.

Также остаётся универсальный OpenAI-compatible адаптер (не обязательно):

```bash
export COVALT_LLM_URL="https://your-provider.example/v1/chat/completions"
export COVALT_LLM_KEY="..."
export COVALT_LLM_MODEL="your-model"
```

Ключи не зашиты в репозиторий и не нужны для проверки интерфейса.

Ollama получает возможность вызвать search tool: Covalt сначала спрашивает,
нужен ли поиск, затем передаёт результаты в следующий запрос модели. Для этого
серверу нужен исходящий HTTPS-доступ к поисковику. Если его нет, Covalt
показывает `CHECK` и прямые ссылки для поиска в браузере, но не выдумывает
источники.

## Что внутри

- `app.py` — Flask-приложение, фоновые задачи, сессия администратора,
  каталог, публикация, удаление, чат, изображения и редактор новостей.
- `covalt_brain.py` — идентичность Covalt, разбор промпта, web search,
  локальный fallback-чат и PNG-режим.
- `video_generator.py` — генератор Covalt: маленькая MLP-сеть на NumPy,
  которая обучается с нуля при запуске на синтетических траекториях и
  предсказывает позицию, размер, вращение и пульсацию объекта во времени;
  программный 2D-растризатор и MP4-энкодер.
- `templates/index.html`, `static/styles.css`, `static/app.js` — интерфейс
  студии без сборщика и без отдельного фронтенд-сервера.
- `data/catalog.json`, `data/news.json` — создаются автоматически; готовые
  MP4, превью и PNG лежат в `data/videos/`, `data/thumbs/`, `data/images/`.
  Эти результаты исключены из Git.
- `dataset.py`, `model.py`, `train.py`, `demo.py` — исходный отдельный
  мультимодальный пример (CNN + GRU), сохранённый в репозитории.

## Настройки

- `COVALT_ADMIN_PASSWORD` — пароль администратора, по умолчанию `9086`.
- `COVALT_SECRET_KEY` — секрет Flask-сессии, обязательно поменяйте на сервере.
- `PORT` — порт, по умолчанию `5000`.

Для создания MP4 используется `imageio-ffmpeg`: пакет поставляет совместимый
FFmpeg-бинарник и не требует ручной установки системного FFmpeg в обычном
виртуальном окружении.
