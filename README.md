# Covalt — мультимодальная нейросеть с нуля (без API)

Минимальный обучаемый пример мультимодальной нейросети на **PyTorch**.
Всё написано с нуля: архитектура, генерация данных, обучение и инференс.

**Без внешних API, без предобученных весов, без скачивания датасетов, без
интернета в рантайме** — изображения рисуются синтетически через numpy,
подписи генерируются из собственного словаря.

## Задача

Модель получает пару **(картинка, текстовая подпись)** и отвечает на вопрос:
описывает ли подпись картинку? (бинарная классификация «совпадает / нет»).

- Картинка — фигура (`circle` / `square` / `triangle`) одного цвета
  (`red` / `green` / `blue`), отрисованная в numpy.
- Подпись — например `"red circle"`.

Это классическая задача мультимодального слияния: правильный ответ нельзя
получить, глядя только на одну модальность — нужно сопоставить обе.

## Архитектура (самописная, `model.py`)

```
картинка (3x32x32) ──► CNN (свёртки+пулинг) ──► вектор 64
подпись  (токены)  ──► Embedding + GRU      ──► вектор 64
                                                 │
                        склейка (128) ──► MLP ──► логит (совпадает?)
```

Два энкодера независимо сжимают каждую модальность в вектор, затем векторы
склеиваются и проходят через MLP. Обучается всё end-to-end (Adam +
BCEWithLogitsLoss).

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python train.py          # обучает ~10 эпох на CPU, секунды
.venv/bin/python demo.py           # показывает предсказания на примерах
```

Флаги обучения: `--epochs`, `--samples`, `--batch`, `--lr`, `--seed`
(см. `python train.py --help`).

## Файлы

| Файл | Назначение |
|------|------------|
| `dataset.py` | синтетические данные + словарь + рендер фигур в numpy |
| `model.py`   | CNN-энкодер картинки, GRU-энкодер текста, fusion-MLP |
| `train.py`   | цикл обучения, сохранение `covalt_model.pt` |
| `demo.py`    | инференс: ASCII-картинка + подпись + вероятность |

## Куда развивать

- Увеличить словарь/сложность подписей (порядок слов, отрицания).
- Заменить GRU на самописный Transformer-энкодер.
- Добавить второй выход (предсказать фигуру и цвет по отдельности).
- Загрузить реальные мультимодальные данные вместо синтетики.
